# Easy Guitar
超简单的离线电吉他编曲工具。
访问链接：https://lovesky514514-cmd.github.io/Easy-Guitar

## 音频效果预览：Easy_Guitar.wav

- Guitar A / B：Piano Roll 主奏
- Guitar C / D：扫弦
- 支持常用吉他演奏技法
- 支持自动演奏优化
- 支持四轨同步播放
- 支持单轨 WAV 导出和混合导出
